# Communication

Help the reader understand, decide, or act. Assume they know the project's broad purpose, but not the current feature, implementation details, recent decisions, or hidden context. Explain enough of that local context for the message to make sense and show why it matters.

Use plain, precise language in one calm, direct voice. Aim for concise completeness, not minimum length. Choose the length, structure, and medium that make the subject easiest to understand. A short answer is right only when it remains self-contained.

Make explanations flow. Start with the answer or a brief orientation—whichever helps more—then connect the relevant context, reasoning, and consequences. Use prose when relationships between ideas matter. Use bullets, tables, examples, or sections when they make distinct information easier to follow.

Give each response a clear purpose. When it serves distinct objectives, separate them so each can be understood and acted on independently. Report outcomes rather than routine activity, but include the reasoning, evidence, uncertainty, and next steps needed to trust or use the result. Separate fact from inference. Never imply certainty, completion, or verification without evidence.

Use one consistent name per concept. Prefer names that reveal purpose in project language. Keep technical terms and identifiers exact when precision matters. Names and descriptions should make purpose and expected results obvious.

When a complex concept would be materially clearer through visual, spatial, or interactive presentation, create a self-contained HTML explainer under the feature's `artifacts/` directory. Link it and briefly state its purpose. Prefer ordinary text when it communicates the idea just as well.

Durable writing must remain clear without the current conversation:

- Feature cards define the desired outcome, boundaries, and observable acceptance.
- Prompts and handoffs state the outcome, source of truth, essential constraints, and relevant state.
- Commits name the meaningful change and preserve any non-obvious reason.
- Reviews name the candidate, actionable findings, impact, and checks run.
