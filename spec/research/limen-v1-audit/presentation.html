02 / THE SYSTEM

Three layers. Three kinds of truth.

Do not turn a terminal status into a job verdict, or a job verdict into permission to merge.

LIMEN / INTENT + EVIDENCE

What are we doing?

Tickets and roles carry intent. Job files record ownership and results. Git carries the candidate and landed history.

PI / EXECUTION

What is the agent doing?

Prompts, tools, sessions, steering, turn events, and model execution belong to Pi. Use its events, not guesses from silence.

HERDR / PRESENTATION

Where can I see it?

Workspaces, tabs, panes, agent identity, and terminal lifecycle belong to Herdr. A label is not a stable identity.

Critical distinction: Herdr done means unseen idle. Limen done means a run ended cleanly. A feature is proven only after its candidate and evidence have been judged.

Responsibility

The human's one conversation

Own the board, choose the next bounded job, inspect results, commission a review when warranted, and integrate accepted work. Do not make the human route messages between workers.

The coordinator decides; workers and reviewers supply candidates and evidence.

04 / WHAT CAN BREAK

Fix the boundaries, not the agent.

The judge retained 15 technical findings with explicit limits and classified the review rubric as a policy choice. Two coordinator observations are also shown. These are counterexamples to reliability—not measurements of production frequency, and not shipped fixes.

05 / A LEANER V1

Less ceremony. Stronger guarantees.

This is a design recommendation, not an instruction to rewrite the harness or widen the current backlog.

KEEP

The judgment stays human-shaped.

  • One coordinator; one repository per job; ordinary Git integration.
  • Short tickets, stable feature numbers, and descriptive tab names.
  • Fresh review for costly mistakes, not a tax on every local edit.
  • Plain durable records, retained evidence, and inspectable recovery.
  • Hosted jobs for interaction; detached jobs for unattended work.
SIMPLIFY

Remove instructions that fight the work.

  • A starting file is a lead, not a fence. Follow necessary dependencies inside the agreed outcome.
  • Escalate product ambiguity, not the eleventh file read.
  • Let a reviewer flag a demonstrated regression even when the ticket did not predict it.
  • Put stable guidance in one place. Recall the one rule relevant to the current operation.
  • Prefer fewer API calls and correct acknowledgements over more timers, retries, or status fields.
A small handoff · prose, not a new schema
Outcome: a worker can finish without the coordinator watching its tab.
Boundary: preserve the existing wake and review semantics.
Starting seam: the supervisor's terminal-result path.
Deliverable: one coherent candidate commit and retained evidence.
Check: kill the caller after launch; the worker must still finish.
Ticket: spec/features/active/<feature>/ticket.md
PI / USE THE NATIVE CONTRACT

Events over imagined promises.

Use structured machine-message identity, final settlement after Pi retries, shutdown reasons, and terminating tool results. Test against the real extension binding. An SDK rewrite is not required.

HERDR / KEEP THE FULL OBSERVATION

Resolve once, control precisely.

Retain terminal identity and the current pane, tab, workspace, and status from one observation. Reuse it within the pass; publish metadata only when it changes.

COMPATIBILITY / CHANGE DELIBERATELY

A newer API is not an installed API.

Upstream tests allow background start without focus theft; the installed server was not proven equivalent. Keep the CLI adapter until measured need justifies owning a socket protocol.

FIRST / MAKE IT SAFE TO LEAVE

Ownership + launch

Remove destructive cleanup of resources whose ownership is unknown. Establish exclusive checkout and terminal publication; resolve current process identity. No new workflow gate.

THEN / MAKE IT QUIET

Notifications + observation

Acknowledge actual consumption. Reuse API snapshots. Keep settled history out of the hot path. Measure the real coordinator.

BEFORE CALLING IT V1

Evidence + subtraction

Run isolated compatibility probes against installed Pi and Herdr. Reconcile contradictory prompts. Demonstrate recovery under failure.
