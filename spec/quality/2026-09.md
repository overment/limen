# Quality findings — 2026-09

## Drop-candidate · Remove the running changed-file counter

The signal that says how many files a running job has changed (F079) is neither complete nor stable enough to justify its path through `src/git.ts`, `src/wrapper.ts`, `src/commands/jobs.ts`, `src/job.ts`, and `src/view.ts`. It is absent for hosted jobs even though hosted is the Herdr default, returns to zero whenever a worker follows the checkpoint-commit instruction, and measures all dirty files rather than work produced by this run. On detached jobs, every parsed activity event—including `message_update`—queues a synchronous `git status`, so a status hint adds a subprocess on a hot stream path. Drop the record, rendering, and dedicated tests instead of extending the same weak signal into hosted mode; tool count, pulse, log, commits, and an inspected worktree already provide the durable evidence.

## Small subtraction slice · Let Markdown own prompt policy

Seven landings in this window added 91 lines to `test/structure.test.ts` that assert exact phrases from the shop manual and role preambles. Those checks make tests a second owner of prose judgment and verify wording rather than observable behavior, contrary to the styleguide. Delete the phrase inventories for research, candidate falsification, retained proof, visual evidence, handoff wording, identifier wording, and spec wording. Keep the structural checks that templates ship with current history hashes and the behavior checks that a named-role spawn loads the packaged preamble.

## Small unification slice · Keep handoff shape in the shop manual

`templates/communication.md` now says a handoff carries one constraint per line and that “its length ceiling stays as it is,” while `templates/agents.md` owns the actual handoff contents, the 200-word ceiling, and the rule that board-owned boundaries are pointed to rather than repeated. The register sentence is contextless and gives the same coordinator two authorities for one artifact. Move the one-constraint instruction beside the complete handoff rule in the shop manual and remove it from the Specs register.

## Proposed ticket line · Project role-model choices override package fallbacks from one source

The research pair and quality/picture models are hard-coded in `templates/agents.md`, repeated in exact-phrase structure tests, and recorded again in `spec/build.md`; a model change can therefore leave three conflicting instructions. Keep generic package fallbacks in the shop manual, make the project board the sole owner of explicit choices and overrides, and stop asserting model names in tests.

## Small subtraction slice · Make the coordinator status static

The settled-history fix removes the expensive reads, but `hook/wake.ts` still writes an unchanged footer every 120 ms solely to animate `SPINNER`. Job facts change on watcher events and the 500 ms sweep; Herdr metadata is already event/sweep driven. Drop the animation interval and frame state, and update one static footer only when the sweep produces a new status. This removes cosmetic CPU work and several timer/error-cleanup branches without changing wake delivery or durable state.

## Small subtraction slice · Remove the unused sweep export

`collectSweep` is exported from `hook/wake.ts` but has no caller outside that file and is not imported by the sweep tests. Make it private so the already-large wake hook does not advertise dead API surface.
