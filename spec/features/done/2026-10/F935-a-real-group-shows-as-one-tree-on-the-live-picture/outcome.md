# Outcome

A real `limen group` (2 teams × 2 workers, OMP `xai-oauth/grok-4.7`) showed on the served picture as one tree: the lead line, both team lines, each coordinator, and its two workers, with counts that matched `limen group status`. The real run exposed three gaps, fixed in `6287b2f`: a group worker whose label names no feature now counts on the group's feature, the lead line shows the group's time left instead of a raw session id, and the strip holds about ten lines so a 2×2 group fits without scrolling. After close and the removal of the group's job records, the strip read "nothing running". The first run failed only because the machine was waiting on disk and missed the 10 s start handshake; the second run used `LIMEN_HANDSHAKE_MS=90000`. Screenshots `real-1` to `real-6` are in this folder.
